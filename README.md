# Vcarda plugins

Plugins for Claude by [Vcarda](https://www.vcarda.com).

## Vcarda Rewards

Design a profitable loyalty rewards card from your menu, then open it in Vcarda
to save it. Connects to the Vcarda Rewards MCP server at
`https://mcp.vcarda.com/mcp`. No account is needed to design a card; sign in
with Vcarda only to see or edit your existing programs.

Install in Claude Code:

```
/plugin marketplace add redakrarssi/vcarda-plugins
/plugin install vcarda-rewards@vcarda-plugins
```

See [vcarda-rewards/README.md](vcarda-rewards/README.md) for details.
Privacy: https://www.vcarda.com/privacy#ai-assistant
